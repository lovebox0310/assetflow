# AssetFlow 정적 프로토타입

`project.md`의 화면 골격을 눈으로 확인하기 위한 정적 목업입니다. React 의존성이 없어
브라우저에서 HTML 파일을 그대로 열면 됩니다.

- 확정 기준: `.ai/project.md` §15(기획), §22-§23(Issue 3·4), §28(디자인/스타일 기준)
- 목표: 와이어프레임 합의 → 확정 디자인을 React + antd 6 + Apache ECharts로 이관

## 보는 법

`index.html`을 브라우저로 엽니다. 빌드·설치·서버가 필요 없습니다.

```
design/prototype/index.html
```

| 파일 | 내용 | 대응 이슈 |
|---|---|---|
| `index.html` | 전체 MVP 정보구조(IA) 맵, 9개 화면 | Issue 3 |
| `login.html` | 이메일 로그인, 오류 상태 | Issue 2 |

| `assets/base.css` | 레이아웃, 공통 컴포넌트 | §28.1 |
| `assets/mock-data.js` | 더미 데이터 + 포맷터 | §28.3 |

## 리뷰할 것

`dashboard.html` 상단의 **상태 미리보기** 버튼으로 Issue 4의 AC를 확인할 수 있습니다.

- **데이터** — 정상 상태. 카드 4종과 차트 표시
- **로딩** — 스피너
- **빈 데이터** — 첫 입력 유도
- **오류** — 재시도 안내

`login.html`과 `settings.html`은 오류 상태를 기본 노출합니다. §21의 "계정 유무를 노출하지
않는 공통 메시지"가 화면에 어떻게 보이는지 확인용입니다.

## 데이터 규칙

`mock-data.js`의 값은 `project.md` §23 "표시 규칙" 공식을 그대로 적용한 결과입니다.

| 카드 | 공식 | 값 |
|---|---|---|
| 순자산 | 총자산 − 총부채 | 385,400,000 − 62,500,000 = **322,900,000원** (축약 3.2억) |
| 월 수지 | 월 총수입 − 월 총지출 | 8,400,000 − 7,160,000 = **+1,240,000원** |
| 비상금 유지 개월 | 보유 현금 ÷ 월 필수지출 | 48,200,000 ÷ 6,700,000 = **7.2개월** |
| 자산 구성비 | 유형별 비율 (합계 100%) | 부동산 41.0 / 주식 37.0 / 현금 12.5 / 연금 9.5 |

축약 표기(`3.2억`)는 카드, 상세 표기(`322,900,000원`)는 상세 화면에 씁니다 (§28.3).
차트는 목업이므로 인라인 SVG이며, 실제 구현은 Apache ECharts로 교체합니다.

## 제약

- **하드코딩 색상 금지** (§28.4). 원시 값은 `tokens.css`의 `:root`에만 있고 나머지는 `var()`만 씁니다.
- **다크 모드 없음** (§28.4). MVP 제외. 추가 시 `theme.darkAlgorithm` 한 줄이면 충분합니다.
- **접근성** (§28.5). WCAG 2.1 AA, 포커스 표시 유지, 폼 라벨은 `for`/`id`로 연결,
  오류는 `role="alert"`. 키보드만으로 전 기능 이동이 가능해야 합니다.
- **antd 미사용**. 이 단계는 레이아웃 합의가 목적입니다. 컴포넌트 구현은 Issue 3에서 합니다.
- `login.html` 폼은 실제 전송 없이 `dashboard.html`로 이동합니다. 인증은 Issue 2 범위입니다.

## Issue 3 화면 증거로 쓰기

`project.md` §9는 UI PR에 화면 캡처를 요구합니다. 리뷰가 끝나면
`dashboard.html`의 모바일(360px) / 데스크톱(1200px) 캡처를 PR에 첨부하면 됩니다.
컨테이너 최대 폭은 1200px입니다 (§28.2).
