# 가계부 카테고리 기준 (§55.10)

**목적**: 카드 내역·수기 지출을 분류할 때 사용하는 **두 단계 카테고리**와 출력 규칙을 정한다.

**버전**: 2026-10-26

---

## 1. 대분류(9개)와 세부 분류

| 대분류 | 세부 분류 | 비고 |
|---|---|---|
| **식비** | 장보기, 외식, 카페/간식, 배달 | 문서의 "고정 식비"는 **장보기**로, 변동비로 본다. |
| **주거/통신** | 주거비, 통신비 | |
| **교통/차량** | 대중교통, 차량유지비 | 자동차 보험료는 **차량유지비**로 둔다. |
| **쇼핑/생활** | 생활용품, 의류/잡화, 가전/가구, 미용/뷰티 | 문서에 없던 **미용**은 쇼핑/생활의 세부로 보충한다. |
| **건강/의료** | 병원비, 약국, 건강기능식품 | |
| **문화/여가** | 취미/여가, 여행/숙박 | **도서 구매**는 문화/여가/취미·여기에 둔다(교육 아님). |
| **금융/세금** | 보험료, 세금/공과금, 저축/투자 | 저축/투자는 **지출이 아닌 자산 이동**으로 지출 합계에서 제외한다. |
| **기타/경조사** | 경조사비, 기타 | |
| **교육** | 학원/교육, 학교/등록금 | 문서에 없던 **교육**을 9번째 대분류로 보충한다. |

---

## 2. 보충 및 예외

- **고정비**: 주거비, 통신비, 보험료, 세금/공과금, 학원/교육
  - 장보기는 문서에서 "고정 식비"라 했지만, 금액이 매달 변하므로 **변동비**로 본다.
- **변동비**: 고정비와 자산 이동을 제외한 나머지 세부 분류.
- **자산 이동**: `저축/투자`는 월 지출 총합에 포함하지 않는다.
- **자동차 보험료**: `교통/차량/차량유지비`로 둔다.
- **도서 구매**: `문화/여가/취미·여가`에 둔다.

## 3. 기존 13종 단일 카테고리 매핑

§55.10 이전에 사용하던 단일 카테고리는 아래와 같이 새 체계로 이관한다.

| 이전 | 새 대분류 | 새 세부(기본값) |
|---|---|---|
| 식비 | 식비 | 미지정 |
| 교통비 | 교통/차량 | 미지정 |
| 보험료 | 금융/세금 | 보험료 |
| 경조사비 | 기타/경조사 | 경조사비 |
| 주거비·통신비, 주거비, 통신비 | 주거/통신 | 미지정 |
| 쇼핑, 미용·의류 | 쇼핑/생활 | 미지정 |
| 의료비 | 건강/의료 | 미지정 |
| 여가/취미 | 문화/여가 | 미지정 |
| 교육비 | 교육 | 미지정 |
| 기타 | 기타/경조사 | 기타 |
| 사업비용 | 기타/경조사 | 기타 |
| 자산취득 | 금융/세금 | 저축/투자 |

이후 `POST /api/v1/assets/card-imports/reclassify` 로 가맹점명 키워드에 맞춰 세부 분류를 채운다.

## 4. 출력 형식 규칙

### 4.1 행 단위

내역을 분석할 때 아래 형태로 정리한다.

```
[날짜 | 사용처(가맹점) | 금액 | 카테고리 | 세부 분류]
```

### 4.2 월 집계

- 매달 **카테고리별 합계 금액**과 **전체 지출 총합**을 계산한다.
- 전체 지출 총합은 **저축/투자(자산 이동)를 제외**한다.
- **고정비**와 **변동비**를 구분해서 보여준다.

### 4.3 CSV 낼출

`ExpensesPage` 의 "CSV 다운로드"는 아래 5개 컬럼으로 낼출한다.

```csv
날짜,사용처(가맹점),금액,카테고리,세부 분류
```
